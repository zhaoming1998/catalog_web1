# 瑞柏晟科技 产品目录网站

在线访问：**https://raybosun.co**

GitHub 仓库：https://github.com/zhaoming1998/catalog_web1

## 项目概述

广东瑞柏晟科技有限公司官方产品目录展示网站，现代化单页应用，纯静态 HTML/CSS/JS 实现，无需后端服务。

## 网站分区

| 分区 | 说明 |
|------|------|
| 首页 Hero | 左对齐编辑式布局，渐变流光标题，金色粒子+网格线+光晕动画，eyebrow 标签 |
| 跑马灯 | 关键词无限滚动（乳液泵头/个人护理/精密制造/品质管控/全球视野），金色圆点分隔 |
| 数据统计 | 黑底分区，左侧标题+右侧 2×2 网格，金色渐变数字+光晕，左竖线分隔 |
| 产品目录 | 401/405两个系列，下划线 Tab 筛选，无边框密集卡片网格，可折叠展开（按需加载图片），hover 金色遮罩 |
| 核心优势 | 2×2 交替网格，带序号 01-04，hover 金色渐变填充 + 顶部金色线条展开 |
| 生产实力 | 文字+大图左右分栏，底部 3 列等宽图廊，金色边框 hover 发光 |
| 关于我们 | 左图右文双栏，特色列表带金色圆点 |
| 资质证书 | ISO9001 证书独立展示 |
| 联系我们 | 左侧联系信息（黑底图标）+ 右侧玻璃拟态表单面板（极简下划线输入框） |
| 页脚 | 品牌简介、快速链接、产品系列、联系方式 |

**页面顺序**：首页 → 跑马灯 → 数据统计 → 产品目录 → 核心优势 → 生产实力 → 关于我们 → 资质证书 → 联系我们 → 页脚

**导航栏**：首页、产品目录、核心优势、关于我们、联系我们

## 设计风格

- **黑金科技感**：深海军蓝背景（`#141C2E` / `#0D1424`）+ 金色品牌强调色（`#D0A252`）
- **视觉语言**：大字号粗体排版、杂志式编辑布局、金色渐变流光、玻璃拟态（backdrop-filter）
- **交互动效**：卡片 hover 金色发光、标题流光动画、跑马灯滚动、数字计数
- **字体**：Google Fonts Noto Sans SC（字重 400/700/900），等宽字体用于产品代号

## 主要功能

- **中英文切换**：首次访问根据浏览器首选语言自动选择中文或英文，用户手动切换后的语言偏好保存在本地
- **响应式设计**：适配桌面、平板、手机
- **导航栏吸顶**：滚动时深色毛玻璃背景 + 金色底边，自动高亮当前分区（金色下划线）
- **跑马灯滚动**：关键词无限横向滚动
- **渐变流光标题**：Hero 标题白金渐变流光动画
- **产品系列折叠**：默认收起，点击"展开产品图库"按钮平滑展开，显示产品数量
- **图片按需加载**：产品图片仅在展开图库时才发起网络请求，首屏不加载
- **系列筛选**：全部系列 / 401 内置弹簧 / 405 外置弹簧 下划线 Tab 快速切换
- **产品编号格式**：前端统一显示为 `R401-33/410A-A-QB` 格式，图片文件名保持不变
- **图片灯箱**：点击产品图片弹出大图，支持左右翻页和键盘操作（Esc关闭、方向键翻页）
- **懒加载背景图**：系列头图通过 IntersectionObserver 接近视口时才加载
- **滚动动画**：元素进入视口时淡入
- **卡片悬浮发光**：hover 金色边框光效 + 渐变填充
- **返回顶部按钮**
- **数字计数动画**：金色渐变数字 + 光晕投影

## 新增产品系列

后续新增系列只需以下步骤：

1. 在 `assets/images/products/` 下新建文件夹（如 `501/`）
2. 将产品图片复制到该文件夹
3. 在 `index.html` 中参照 401/405 的结构添加新的 `product-series` 区块（包含 series-header、series-toggle、product-grid-wrapper）
4. 在 `main.js` 中添加对应的文件列表数组（如 `files501`）并在 `renderProducts()` 中调用 `renderSeries()`
5. 在筛选按钮区域和联系表单的下拉选项中添加新系列
6. 在 I18N 的 zh/en 对象中添加新系列的翻译文本

## 图片优化记录

### 第一轮：JPEG 压缩

图片使用 macOS `sips` 工具统一转为 JPEG 并压缩：

| 类别 | 原始大小 | 压缩后 | 缩减 |
|------|----------|--------|------|
| 产品图(401) 38张 | - | ~724KB | - |
| 产品图(405) 18张 | - | ~328KB | - |
| 横幅图 | 18MB+ | ~600KB | 97% |
| 工厂图 4张 | 16MB | ~1.4MB | 91% |
| **总计** | **~47MB** | **~3.3MB** | **93%** |

压缩参数：
- 产品图：最长边 600px，JPEG 质量 55%
- 横幅图：最长边 1600-1920px，JPEG 质量 60-70%
- 工厂图：最长边 1200px，JPEG 质量 55%

### 第二轮：WebP 转换 + 深度优化

使用 Node.js `sharp` 库将全站图片转为 WebP 格式，同步优化尺寸：

| 文件 | 优化前 | WebP | 缩减 |
|------|--------|------|------|
| logo.jpg | 395KB (1926px) | 1.7KB (200px) | 99.6% |
| hero-bg.jpg | 258KB | 43KB | 83% |
| banner401.jpg | 110KB | 21KB | 81% |
| banner405.jpg | 94KB | 20KB | 79% |
| equipment.jpg | 882KB | 45KB | 95% |
| factory.jpg | 223KB | 142KB | 36% |
| 产品图 401 (38张) | ~400KB | ~324KB | ~19% |
| 产品图 405 (18张) | ~200KB | ~128KB | ~36% |

WebP 压缩参数：
- 产品图：quality 65
- 横幅/工厂/logo：quality 70

### 加载优化策略

1. **关键资源预加载**：Hero 背景图和 Logo 通过 `<link rel="preload">` 提前加载（WebP 格式）
2. **产品图按需加载**：使用 `data-src` 占位，仅在展开图库时才赋值 `src` 发起请求
3. **背景图懒加载**：系列头图通过 `IntersectionObserver` 进入视口 200px 时才加载
4. **原生懒加载**：工厂、关于等区域图片使用 `loading="lazy"`
5. **图片淡入**：加载完成后平滑显示，避免布局抖动
6. **WebP 格式**：全站图片提供 WebP 版本，浏览器支持时自动加载（平均比 JPEG 小 50-80%）
7. **WebP 兼容回退**：`<picture>` 标签 + JS 检测，不支持 WebP 时自动回退 JPG
8. **Google Fonts 异步加载**：减少字重（仅保留 400/700/900），`media="print"` 异步加载不阻塞渲染
